# Assets

Upload files here for the game. Use the GitHub website: open a folder below, click **Add file → Upload files**, drag your files in and **Commit changes**.
(Website limit: 25 MB per file, ~100 files per upload. Bigger packs: split into several ZIPs or use GitHub Desktop.)

| Folder | What goes in it |
|---|---|
| `music/` | Stage music (stages 1–6, random shuffle) — MP3/OGG |
| `music/final/` | Final boss music (Celestial Throne, stage 7) |
| `packs/` | Whole asset packs (ZIP or folders), one subfolder per pack, e.g. `packs/fantasy-world/` |
| `textures/` | Single textures (PNG/JPG), ideally seamless — say what they're for |
| `models/` | Single 3D models (GLB/glTF preferred, FBX/OBJ ok) — say what they're for |

Only upload assets you're allowed to put in a **public** repo (CC0 / public domain is ideal).
